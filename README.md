# Практика Go

Тренируюсь писать на Go.

**1 день:** объявление переменных, нулевые значения, функции, условия, аргументы командной строки, преобразование строк в числа, обработка ошибок и табличные тесты.

**2 день:** массивы и слайсы, len и cap, append, map, обход коллекций через range, строки, byte и rune, UTF-8 и табличные тесты.

**3 день:** структуры, нулевые значения, указатели, адреса и разыменование, методы с получателями по значению и указателю, валидация, обработка ошибок и табличные тесты.

**4 день:** интерфейсы и их неявная реализация, наборы методов, копирование значений и указателей, nil в интерфейсах, слайсы интерфейсов и тестирование изменения состояния объектов.

**5 день:** JSON, сериализация и десериализация, теги структур, валидация данных, чтение и запись файлов, временные папки и тестирование файловых операций.

**6 день:** оборачивание ошибок через %w, сигнальные ошибки, errors.Is и errors.As, распознавание причин и типов ошибок, тестирование обработки ошибок. В task.json намеренно указан неверный тип поля done для демонстрации errors.As.

**7 день:** собственные типы ошибок, интерфейс error, извлечение данных через errors.As, различия %w и %v, типизированный nil и тестирование ошибок.

**8 день:** defer, порядок отложенных вызовов и вычисление аргументов, открытие и закрытие файлов, чтение через io.ReadAll, обработка файловых ошибок через errors.Is и errors.As, тесты с временными файлами.

**9 день:** интерфейс io.Reader, чтение из строк и файлов, тестовые источники данных, повторное чтение, EOF, частичные данные и ошибки. Пример запускается из корня репозитория и читает day08/message.txt.
